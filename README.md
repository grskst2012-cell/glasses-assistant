# Glasses Assistant
Голосовой ассистент (русский) для Ray-Ban Meta через Bluetooth. LLM: любой OpenAI-совместимый API.

1. Открой папку в Android Studio, дождись Gradle sync, Run на телефоне.
2. Подключи очки к телефону по Bluetooth как обычно.
3. В приложении: URL / ключ / модель (кнопка «Показать модели» откроет список), слово пробуждения, «Старт».
4. Разреши работу без ограничений батареи — тогда ассистент слушает в фоне.

Пресеты:
- DeepSeek: https://api.deepseek.com , deepseek-chat
- Kimi: https://api.moonshot.ai/v1 , модель из консоли Moonshot
- OpenRouter (есть :free модели): https://openrouter.ai/api/v1
