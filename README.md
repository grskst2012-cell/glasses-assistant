# Glasses Assistant

![Platform](https://img.shields.io/badge/platform-Android%2012%2B-3DDC84?logo=android&logoColor=white)
![Kotlin](https://img.shields.io/badge/Kotlin-2.0-7F52FF?logo=kotlin&logoColor=white)
![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-Material%203-4285F4?logo=jetpackcompose&logoColor=white)
![License](https://img.shields.io/badge/license-MIT-green)

Голосовой ассистент на русском для умных очков (Ray-Ban Meta и любых других Bluetooth-очков и наушников).
Работает в фоне, слушает через микрофон очков, отвечает голосом и не выдумывает факты: время, погоду, курсы валют и справки берёт из источников и называет их.

> Проект личный и экспериментальный. На реальных очках пока не проверялся.

## Возможности

- **Фоновая работа.** Foreground-сервис с постоянным уведомлением, кнопки «Говорить», «Микрофон» и «Стоп» прямо в нём.
- **Слово пробуждения.** Своё слово или фраза («ассистент, который час?» работает одной фразой). Можно отключить и пользоваться кнопкой.
- **Короткие ответы для слуха.** Суть в начале, числа и единицы словами, без markdown. Подробности по команде «подробнее».
- **Проверяемые факты.** Модель вызывает инструменты и называет источник и время данных:
  - время и дата, с телефона;
  - погода — [Open-Meteo](https://open-meteo.com);
  - курсы валют — ЦБ РФ ([cbr-xml-daily.ru](https://www.cbr-xml-daily.ru));
  - справка — русская Википедия.
- **Голосовые команды без обращения к модели.** «Стоп» / «тихо», «повтори», «помедленнее», «побыстрее», «подробнее».
- **Любой OpenAI-совместимый API.** DeepSeek, OpenRouter, Kimi, Yandex AI Studio и другие: достаточно URL, ключа и модели. Список моделей загружается кнопкой, с поиском и фильтром `:free`.
- **Material 3.** Динамические цвета, тёмная тема, анимированный индикатор состояния (ожидание, слушаю, думаю, говорю, микрофон выключен), история диалога, быстрые команды, текстовый ввод, виброотклик, поддержка TalkBack.
- **Понятные ошибки.** «Нет связи», «Проверьте ключ», «Модель перегружена» вместо тишины.

## Как это работает

```
микрофон очков ─► SpeechRecognizer (ru-RU) ─► LlmClient ──► инструменты (время, погода, курс, Википедия)
                                                  │
динамики очков ◄─ TextToSpeech (ru) ◄─────────────┘
```

| Файл | Назначение |
|---|---|
| `AssistantService.kt` | Фоновый сервис: аудио через Bluetooth, цикл слушаю → думаю → говорю, слово пробуждения, локальные команды, состояние для интерфейса |
| `LlmClient.kt` | Клиент `/chat/completions` с историей и циклом вызова функций, понятные ошибки |
| `Tools.kt` | Инструменты и кэш: время, Open-Meteo, ЦБ РФ, Википедия |
| `AssistantScreen.kt` | Экран диалога: индикатор состояния, кнопки, история, ввод текстом |
| `SettingsScreen.kt` | Настройки: голос, данные, модель и ключ, фон, приватность |
| `MainActivity.kt` | Тема и навигация |

## Требования

- Android 12 или новее (`minSdk 31`)
- Bluetooth-очки или наушники (необязательно: без них используется микрофон телефона)
- Ключ API любого OpenAI-совместимого провайдера
- Для сборки: Android SDK 35, JDK 17–21, Gradle 8.9+

## Сборка и установка

```bash
git clone https://github.com/grskst2012-cell/glasses-assistant.git
cd glasses-assistant
```

1. Откройте папку в Android Studio и дождитесь Gradle sync, затем **Run** на телефоне.
2. Или соберите из консоли (в `local.properties` должен быть путь `sdk.dir=...` к Android SDK):

   ```bash
   gradle :app:assembleDebug
   ```

   APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

> JDK 25 не подходит для Kotlin 2.0.21, используйте JDK 17–21. Если путь к проекту содержит не латинские символы, добавьте `-Pandroid.overridePathCheck=true`.

## Настройка

1. Подключите очки к телефону по Bluetooth как обычные наушники.
2. Откройте **Настройки** → **Модель и ключ**: вставьте URL, ключ и модель. «Показать модели» откроет список, выбор сохраняется сразу.
3. Для погоды укажите свой город в разделе **Актуальные данные**.
4. Нажмите **Снять ограничения батареи**, чтобы система не усыпляла ассистента.
5. На вкладке **Диалог** нажмите **Запустить ассистента** и разрешите микрофон и уведомления.

Примеры провайдеров:

| Провайдер | Base URL | Модель |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| OpenRouter | `https://openrouter.ai/api/v1` | любая, в том числе с `:free` |
| Kimi (Moonshot) | `https://api.moonshot.ai/v1` | из консоли Moonshot |

Проверка фактов через инструменты работает, только если модель поддерживает вызов функций. Если не поддерживает, ассистент отвечает без источников.

## Использование

- Скажите слово пробуждения: «**ассистент**, какая погода?» или просто «ассистент» и после сигнала команду.
- Или нажмите **Говорить** в приложении или в уведомлении.
- После ответа можно продолжить разговор без слова пробуждения; при тишине ассистент снова ждёт слово.
- «Стоп», «повтори», «помедленнее», «подробнее»: выполняются сразу, без запроса к модели.

## Ограничения

- Слово пробуждения построено на системном распознавании речи Android: оно заметно тратит батарею, на части прошивок пищит при перезапуске и может использовать сеть. Надёжнее кнопка «Говорить».
- Микрофонный сервис нельзя запустить из фона (правило Android 14+): запускать нужно из открытого приложения.
- Пока ассистент говорит, микрофон выключен, перебить его голосом нельзя (кнопка «Тихо» работает).
- Качество Bluetooth-микрофона зависит от очков и кодека; поведение Ray-Ban Meta как гарнитуры не проверено.
- Бесплатные модели и провайдеры бывают нестабильны (ошибка 429), а доступность зависит от региона.

## Приватность

Ключ API и настройки хранятся только на телефоне. Запросы отправляются выбранному вам провайдеру модели; для погоды передаётся только название города, без координат. История диалога хранится в памяти приложения и очищается в настройках. Пока ассистент запущен, Android показывает значок микрофона.
